# Vocabulary Usage: 200 Practical Sentences

Vocabulary is useful only when you can use it in real sentences.

## First Principles

Do not learn words alone. Learn:

- meaning
- sentence
- collocation
- tone
- situation

## Daily Method

1. Pick 5 words.
2. Write one simple sentence for each.
3. Write one professional sentence for each.
4. Speak both aloud.
5. Use one word in a real message.

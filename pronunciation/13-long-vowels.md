# Long Vowels

## 1. Why this matters

Long vowels change meaning. Sheep is not ship. Pool is not pull.

## 2. First principles explanation

A long vowel is held longer and often uses a stronger mouth position.

## 3. Simple explanation

Long vowels take more time than short vowels.

## 4. Explain like I am 12

A long vowel is like holding a note in music for a little longer.

## 5. Real examples

- sheep
- beat
- pool
- leave
- seat

## 6. Common mistakes

- sheep -> ship
- leave -> live
- pool -> pull

## 7. Correct vs incorrect

- Incorrect: I will live now.
  Correct: I will leave now.
- Incorrect: The pull is clean.
  Correct: The pool is clean.

## 8. American vs British difference, if applicable

Both accents use long vowel contrasts. The exact sound can differ, but the contrast must stay clear.

## 9. Practice

1. Say: ship/sheep.
2. Say: live/leave.
3. Say: pull/pool.

## 10. Answer key

1. The second word is longer.
2. The mouth position is stronger.
3. Meaning changes if the vowel changes.

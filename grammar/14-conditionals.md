# Conditionals

## 1. Why this matters

Conditionals show cause, result, possibility, and imagination. helps you make clear English. When this topic is weak, your listener has to guess your meaning.

## 2. First principles explanation

English starts with meaning. To express meaning, choose the right word role, place it in the right position, and connect it to the rest of the sentence.

## 3. Simple explanation

Conditionals is a tool for building clear sentences. Learn the pattern, see examples, then use it in your own speaking and writing.

## 4. Explain like I am 12

Think of a sentence like a small machine. Each part has a job. Conditionals teaches one job in that machine.

## 5. Real examples

- If you share the logs, I can check.
- If the server fails, the job stops.
- If I had access, I would verify it.

## 6. Common mistakes

- If you will share logs, I will check. -> If you share the logs, I will check.
- If I was you. -> If I were you.
- If it will fail. -> If it fails.

## 7. Correct vs incorrect

- Incorrect: If you will share logs, I will check.
  Correct: If you share the logs, I will check.
- Incorrect: If I was you.
  Correct: If I were you.
- Incorrect: If it will fail.
  Correct: If it fails.

## 8. American vs British difference, if applicable

No major difference for normal daily use. Use one style consistently.

## 9. Practice

1. Correct: If you will confirm, I will proceed.
2. Complete: If I get access, ...
3. Write one work conditional.

## 10. Answer key

1. If you confirm, I will proceed.
2. Example: I will test it.
3. If the build fails, I will check the logs.

## 12. Daily drill

# IELTS Writing Task 1 Academic

## Goal

Write a clear 170-190 word report in 20 minutes.

## First Principles

Task 1 is not an essay. It is a report.

You must:

- summarize key features
- compare important data
- avoid personal opinion
- organize logically
- use accurate trend language

## 4-Paragraph Structure

1. Introduction: paraphrase the question.
2. Overview: main trends or key features.
3. Body 1: first main comparison.
4. Body 2: second main comparison.

## Band 8 Checklist

- Clear overview
- Accurate data selection
- Strong comparisons
- No opinion
- No over-description
- Good grammar control

## Useful Language

| Function | Examples |
| --- | --- |
| Increase | rose, increased, grew, climbed |
| Decrease | fell, declined, dropped, decreased |
| No change | remained stable, stayed constant |
| Big change | rose sharply, fell significantly |
| Small change | increased slightly, declined marginally |
| Comparison | whereas, while, compared with, in contrast |

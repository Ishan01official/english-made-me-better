# IELTS Reading System

## Goal

Reach 36/40 in practice and finish all questions within 60 minutes.

## Core Principle

IELTS Reading is a paraphrase test. The answer is rarely written in the same words as the question.

## Question Types

| Type | Risk | Strategy |
| --- | --- | --- |
| True/False/Not Given | confusing false and not given | Check whether information is contradicted or absent |
| Matching headings | choosing attractive but partial headings | Find the main idea, not one detail |
| Matching information | time loss | Search names, dates, unique nouns first |
| Sentence completion | grammar mismatch | Predict answer type and check grammar |
| Summary completion | word limit errors | Respect word limit exactly |
| Multiple choice | traps | Eliminate wrong answers with evidence |

## 3-Pass Method

1. Passage overview: title, first lines, topic.
2. Questions: identify type and keywords.
3. Evidence: locate answer and verify.

## Band 8 Reading Habits

- Do not read every sentence at the same speed.
- Skim for structure.
- Scan for names, dates, and technical words.
- Underline paraphrases.
- Move on if stuck for more than 90 seconds.

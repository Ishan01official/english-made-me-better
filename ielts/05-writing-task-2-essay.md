# IELTS Writing Task 2 Essay

## Goal

Write a clear 270-310 word essay in 40 minutes.

## First Principles

Task 2 tests your ability to answer an argument question clearly.

You need:

- position
- reasons
- examples
- paragraph control
- grammar range
- topic vocabulary

## Essay Types

| Type | What To Do |
| --- | --- |
| Opinion | Give your opinion and support it |
| Discussion | Discuss both views and give your opinion if asked |
| Advantages/Disadvantages | Explain both sides and evaluate if required |
| Problem/Solution | Explain causes/problems and practical solutions |
| Two-part question | Answer both questions directly |

## Band 8 Essay Structure

1. Introduction: paraphrase + clear position.
2. Body 1: main idea + explanation + example.
3. Body 2: second idea + explanation + example.
4. Conclusion: answer again, no new idea.

- Did I answer all parts?

- Did I use examples naturally?
- Are there repeated grammar errors?

# IELTS Resources

Use this file as your resource directory. Prefer official IELTS sources first, then use books and videos for extra practice.

## Recommended Books

Do not copy book content into this repo. Use these books for timed practice and review.

| Book | Best for | How to use |
| --- | --- | --- |
| The Official Cambridge Guide to IELTS | Full IELTS strategy and practice | Study one skill chapter, then do timed tasks |
| Cambridge IELTS Academic series | Realistic test practice | Use for mock tests and error logging |
| IELTS Trainer | Guided practice and test training | Use before full mocks |
| Collins Writing for IELTS | Writing Task 1 and Task 2 development | Use for structure, vocabulary, and controlled writing |
| Collins Speaking for IELTS | Speaking fluency and topic vocabulary | Use for Part 1, Part 2, and Part 3 practice |
| English Grammar in Use | Grammar accuracy | Use to fix repeated grammar errors |
| Practical English Usage | Advanced grammar and usage doubts | Use as a reference, not a cover-to-cover book |

## Rule For Using Resources

1. Official sample tests first.
2. Cambridge books for mock-test practice.
3. YouTube only for explanation and listening exposure.
4. Every resource must produce output: notes, corrections, speaking recording, or a timed answer.

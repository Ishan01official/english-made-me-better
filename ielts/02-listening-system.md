# IELTS Listening System

## Goal

Reach 36/40 in practice so test-day variation still keeps you near Band 8.

## Question Types

| Type | Risk | Strategy |
| --- | --- | --- |
| Form completion | spelling, numbers, names | Predict answer type before listening |
| Note completion | missing paraphrase | Underline keywords and listen for synonyms |
| Multiple choice | distractors | Wait for final answer, not first mention |
| Matching | speed | Track speakers and options carefully |
| Map/diagram | direction language | Pre-read labels and follow movement |

## Daily Drill

1. Listen once under test conditions.
2. Check answers.
3. Listen again with transcript if available.
4. Write the reason for each wrong answer.
5. Add new phrases to vocabulary.

## Band 8 Listening Habits

- Predict noun, verb, number, date, or adjective.
- Watch singular/plural.
- Write exact spelling.
- Do not stop after one missed answer.
- Learn paraphrase: price = cost, issue = problem, residence = accommodation.

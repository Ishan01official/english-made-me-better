# IELTS 150-Day Study Plan For Band 8

Target: minimum IELTS Band 8.

Assumption: you study 90-120 minutes on weekdays and 3-4 hours on weekends. If you have less time, keep the same order but reduce volume, not error review.

## Phase Summary

| Phase | Days | Main Goal |
| --- | --- | --- |
| Foundation | 1-30 | Understand IELTS, fix basic mistakes, build daily routine |
| Skill Build | 31-75 | Learn every question type and task structure |
| Band 8 Upgrade | 76-120 | Timed practice, high-level answers, repeated correction |
| Exam Simulation | 121-150 | Full mock tests and test-day control |

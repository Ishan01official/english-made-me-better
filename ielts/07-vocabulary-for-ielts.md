# Vocabulary For IELTS Band 8

## First Principles

IELTS vocabulary is not about rare words. It is about accurate, flexible, topic-specific words.

## Topic Vocabulary Sets

| Topic | Useful Words | Example Sentence |
| --- | --- | --- |
| Education | curriculum, assessment, literacy, discipline | A balanced curriculum should develop both knowledge and critical thinking. |
| Technology | automation, privacy, innovation, access | Automation can improve productivity, but it may also reduce some jobs. |
| Environment | emissions, conservation, renewable, biodiversity | Governments should invest more in renewable energy. |
| Health | prevention, treatment, lifestyle, nutrition | Prevention is often more effective than expensive treatment. |
| Work | flexibility, productivity, workload, collaboration | Flexible work can improve productivity when managed well. |
| Cities | infrastructure, congestion, housing, public transport | Better public transport can reduce congestion. |
| Crime | prevention, rehabilitation, punishment, offender | Rehabilitation can help offenders return to society. |
| Media | influence, bias, coverage, audience | Media coverage can influence public opinion. |

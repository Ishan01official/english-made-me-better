# Contributing

This repo is a personal learning system. Contributions should keep the project simple, practical, and beginner friendly.

## Rules

- Use Markdown for lessons.
- Use Mermaid for diagrams.
- Use JSON for practice data.
- Use Python only for simple checking scripts.
- Do not add a database or web framework.
- Do not copy copyrighted book content.
- Add original examples and answer keys.

## Lesson Checklist

- Simple explanation
- First principles explanation
- Real examples
- Common mistakes
- Practice
- Answer key
- Feynman teach-back exercise
